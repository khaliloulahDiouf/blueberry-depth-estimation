# Blueberry Field Depth Estimation Using Deep Learning

## Project Overview

This project was developed as part of my Master's research in Mathematics and Applied Computer Science at Université du Québec à Trois-Rivières (UQTR), Canada.

The goal is to estimate depth from RGB images of natural blueberry fields using deep learning.

## Technologies

- Python
- PyTorch
- GLPN (Global-Local Path Networks)
- OpenCV
- NumPy
- Google Colab

## Methodology

The project uses RGB images and corresponding depth maps captured with an Intel RealSense camera.

A pretrained GLPN model was adapted to estimate depth in natural agricultural environments.

The work includes image preprocessing, data augmentation, model training, and performance evaluation.

## Technical Challenges

The main challenges include changing lighting conditions, complex vegetation, and invalid depth measurements.

## Current Status

The project is being prepared for reproducible use. The training and evaluation notebooks are under review, and the final experimental results have not yet been independently reproduced from the available files.
